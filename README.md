# Full Stack CRUD Admin

Sistema Full Stack moderno com Node.js, Express, MySQL e Frontend Admin.

## Tecnologias

- Node.js
- Express
- MySQL
- JavaScript
- HTML
- CSS
- Git/GitHub
- Postman

## Funcionalidades

- Listar utilizadores
- Criar utilizador
- Editar utilizador
- Remover utilizador
- Buscar utilizadores
- Validação backend
- Toast de feedback
- Modal de confirmação
- Tratamento de erros

## Como rodar o projeto

```powershell
npm install
npm run dev
